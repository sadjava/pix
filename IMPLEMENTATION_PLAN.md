# План реализации

Офлайн-редактор пиксельных ковров. Локальный документ — источник истины. Облако — резервные снимки.

## Команды

```bash
npm install
npm run dev
npm run typecheck
npm run lint
npm test
npm run build
```

CI (`.github/workflows/ci.yml`) запускает typecheck, lint, test и build. Публикация на GitHub Pages — `.github/workflows/deploy.yml`, артефакт `dist` без пользовательских проектов.

## Модули

- `src/editor` — клетки, координаты, инструменты, симметрия, выделение, история, сессия жестов.
- `src/data` — Dexie, репозиторий, очередь сохранения, квота и persistent storage.
- `src/export` — PNG из модели, JSON, SHA-256, gzip.
- `src/backup` — протокол, outbox, планировщик, память для тестов, адаптер Supabase.
- `src/projects`, `src/editor/EditorScreen.tsx` — галерея и редактор.
- `supabase/migrations/001_backups.sql` — таблица версий, приватный bucket, RLS.

## Риски

- Chrome может вытеснить IndexedDB. Кнопка в галерее запрашивает persistent storage и показывает оценку квоты. Отказ не блокирует редактор.
- Бесплатный проект Supabase может встать на паузу. Рисование от этого не зависит.
- Заливка 500×500 идёт на главном потоке одним массивом отметок. Если на планшете она заметно замирает, следующий шаг — перенос в worker.
- Жест двумя пальцами и `pointercancel` нужно проверить на Android. В коде второй указатель отменяет рисование и масштабирует холст.
- Имя репозитория GitHub и ключи Supabase нужны только для публикации и облака. Локально приложение работает без них.
